# psyteeth.ru (fusion) — сайт «Психостоматология №1», версия-карта

Новая структура сайта: одна страница-карта из связанных кругов. Контент взят из `psyteeth/rusite` (статический перенос с Тильды).
Чистый HTML/CSS/JS, без сборки и зависимостей.
Хостинг: GitHub Pages, репозиторий `psyteeth/fusionsite`, ветка `main`, корень.

- Тест: https://psyteeth.github.io/fusionsite/
- Живой psyteeth.ru пока на Тильде. DNS не трогать, в аккаунты регистратора и Тильды не входить.

## Концепция (по эскизам и диктовке пользователя)
- Главная: в центре большой круг «Психостоматология №1», вокруг 4 раздела: Услуги, Блог, Эфиры, Задать вопрос. У каждого раздела свои маленькие сателлиты, симметрично по кругу (у Услуг и Вопроса крупнее, у Блога и Эфиров мельче).
- Клик по разделу: он выезжает в центр и становится большим, его сателлиты расходятся лучами вокруг (каждый связан линией с центром). Остальное сворачивается в «молекулу» (зубик + $, документ, ▶, ?) в угол: Блог — левый нижний, Эфиры — левый верхний, Услуги — правый нижний, Вопрос — правый верхний.
- Клик по большому кругу «Психостоматология» на главной: он увеличивается, разделы уходят маленькими в свои углы. Повторный клик — назад.
- Всё слегка «плавает», связи всегда видны. Адреса: `#uslugi`, `#blog`, `#efiry`, `#vopros`, `#psy`.

## Где что лежит
- `index.html` — главная-карта. Внутри: `<nav id="plain">` (обычные ссылки для поиска и для работы без JS), `<dialog id="modal">`, блок `#details` — тексты услуг (показываются в модалке по клику на сателлит).
- `assets/js/graph.js` — данные карты (`HUBS`, `LEAVES`) и вся логика: раскладка, анимация, навигация, модалка.
- `assets/css/graph.css` — стили карты.
- `tpost/<slug>/index.html` — статьи блога (из rusite). URL совпадают с тильдовскими, папки не переименовывать.
- `assets/css/style.css`, `assets/js/main.js` — стили и скрипт страниц статей (из rusite).
- `assets/img/` — все картинки.
- `404.html` — страница ошибки + редирект старых ссылок `/tpost/<uid>…` на статью.
- `sitemap.xml`, `robots.txt`, `.nojekyll`.
- Фото-референсы (`*.HEIC`) лежат локально и в git не идут (`.gitignore`).

## Правила
- Все пути внутри сайта **относительные** (`assets/...`, `../../assets/...`, `./tpost/.../`), никогда не начинать с `/`: сайт открывается из подпапки `/fusionsite/`.
- Исключения: canonical, og:url, og:image и JSON-LD — абсолютные `https://psyteeth.ru/...`.
- Тексты — авторские. Править только то, что просит пользователь; стиль, тире и пунктуацию не «улучшать». Тексты-черновики (ИИ-саммари) помечены `draft: true` в `HUBS` и показываются с пометкой «[черновик]» до утверждения.
- Не добавлять зависимостей от Tilda и внешних CDN (шрифты тоже). Новые картинки — в `assets/img/`.
- Файл `CNAME` не создавать, пока пользователь не скажет переезжать на psyteeth.ru.
- Каждая правка — отдельным коммитом. Перед пушем показать diff (было → стало) и дождаться подтверждения.

## Как добавить / поменять
- Сателлит раздела: строка в `LEAVES` в `graph.js` (`parent` — id раздела; `href` — ссылка, `detail` — id блока в `#details` для модалки, `img` — обложка из `assets/img/`, `inner` — текст/цена в круге). Сателлит сателлита — `parent` = id сателлита (как «Зубное кунг-фу» у «Групповой работы»).
- Новая статья: скопировать папку статьи в `tpost/<slug>/`, поправить мета-теги и текст; добавить строку в `LEAVES` (parent `blog`), ссылку в `<nav id="plain">` и в `sitemap.xml`; uid — в карту редиректов `404.html`.
- Эфиры: сейчас 9 заглушек (`placeholder: true`), список будет позже.

## Проверка
Превью `fusionsite` в `../.claude/launch.json`: сервер на 8937 отдаёт родительскую папку → http://localhost:8937/fusionsite/ (как на Pages, из подпапки).
Смотреть на ширине ~1280 и ~375, все разделы и `#psy`, без ошибок в консоли.
Быстрая проверка путей: ни одного `src="/` или `href="/` (кроме `//`) в html-файлах.

## Публикация
Перед пушем, если менялись `graph.css` или `graph.js`, увеличить номер версии в `index.html` (`graph.css?v=N`, `graph.js?v=N`): иначе телефоны показывают старые файлы из кэша (Pages кэширует на 10 минут). Пользователю давать ссылку с тем же `?v=N`.

Commit + `git push origin main` → GitHub Pages пересобирается сам за ~1 минуту (Pages включает пользователь: Settings → Pages → Deploy from branch → `main` / root).
